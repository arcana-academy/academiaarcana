## Purpose

Official visual motif for Missions. It frames a mission as a clear document of purpose: objective, action, progress and completion.

## Visual construction

- academic document silhouette;
- restrained fold detail;
- concentric target representing a defined purpose;
- violet/gold treatment;
- transparent, scalable SVG delivery.

## Usage

Use on Mission surfaces where the page already communicates the mission context.

## Accessibility

In application UI the image is decorative and uses an empty `alt`; the surrounding copy carries the semantic meaning.

## Restrictions

Do not use the document motif to imply completion, failure or reward without explicit application state.
