# AA-VIS-006 — Sigilo de Foco

Status: CANONICAL
Version: 1.0
Category: focus / stability
File: `public/assets/focus/aa-focus-sigil.svg`

## Purpose

Official visual symbol for Focus. It represents silence, stability, rhythm and a contained point of attention.

## Visual construction

- circular field with contained concentric geometry;
- four directional anchors;
- central diamond and stable nucleus;
- restrained violet/gold treatment;
- transparent, scalable SVG delivery.

## Usage

Use on Focus surfaces where the surrounding UI already communicates the session context.

## Accessibility

In application UI the image is decorative and uses an empty `alt`; nearby text supplies the semantic meaning.

## Restrictions

Do not use the sigil to communicate danger, urgency, failure or performance ranking.
