# Academia — Learning Area Icons

Status: CURRENT / LEGACY IMPLEMENTATION  
Validation: PENDING — Fase 2 / Linguagem do Mundo  
Category: functional custom icons

Current visual assets for the three primary learning entry points shown on the Academia page.

- **AA-ASSET-010** — `aa-workspace.svg`: organization of knowledge / grimoire.
- **AA-ASSET-011** — `aa-cronograma.svg`: planning / time / rhythm.
- **AA-ASSET-012** — `aa-sanctuary.svg`: orientation / continuity / sanctuary.

The icons currently use a shared geometric vocabulary, restrained gold/violet treatment, clear silhouettes, transparent backgrounds and scalable SVG delivery.

In the application they are decorative and use an empty `alt`; the adjacent text supplies the semantic label.

## Phase 2 governance

These icons remain operational CURRENT implementations. Their custom geometry must be validated against the Phase 2 role taxonomy and against Lucide React before any final-canon promotion. A custom icon is justified only when the standard functional icon vocabulary is insufficient or when an approved identity requirement demands a custom mark.

AA-ASSET is the identifier namespace for these deliverables; AA-VIS remains reserved for visual-system decisions.
