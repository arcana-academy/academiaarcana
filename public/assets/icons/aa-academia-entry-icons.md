# Academia — Learning Area Icons

Approved visual assets for the three primary learning entry points shown on the Academia page.

- **AA-VIS-ICON-003** — `aa-workspace.svg`: organization of knowledge / grimoire.
- **AA-VIS-ICON-004** — `aa-cronograma.svg`: planning / time / rhythm.
- **AA-VIS-ICON-005** — `aa-santuary.svg`: orientation / continuity / sanctuary.

The icons use a shared geometric vocabulary, restrained gold/violet treatment, clear silhouettes, transparent backgrounds and scalable SVG delivery.

In the application they are decorative and use an empty `alt`; the adjacent text supplies the semantic label.
