# AA-VIS-002 — Sanctuary Sigil

Status: CANONICAL
Version: 1.0
Category: sanctuary / identity
File: `public/assets/sanctuary/aa-sanctuary-sigil.svg`

## Purpose

Dedicated atmospheric sigil for the Santuário, expressing orientation, continuity and calm without replacing the institutional seal.

## Visual construction

- open circular arc;
- restrained academic-arcane geometry;
- open-book motif;
- central nucleus;
- gold and violet accents;
- transparent background;
- scalable SVG delivery.

## Approved uses

- Santuário hero atmosphere;
- Sanctuary-specific empty states and orientation surfaces when explicitly mapped;
- future Sanctuary illustrations requiring the same semantic symbol.

## Accessibility

The SVG has an internal title and description for direct document use. In the application hero it is intentionally decorative and therefore uses an empty `alt`.

## Restrictions

Do not use it as a replacement for the institutional seal, navigation icon, or achievement badge. Do not depend on color alone to communicate a state.
