# Security Policy

## Supported Versions

The Academia Arcana project is currently under active development.

Security fixes are applied to the current development version of the project.

| Version | Supported |
| ------- | --------- |
| Current | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in Academia Arcana, please report it privately.

Do not disclose security vulnerabilities through public GitHub Issues, pull requests, or other public channels.

Please provide:

- a clear description of the vulnerability;
- the affected component or file, if known;
- steps to reproduce the issue;
- the potential security impact;
- any relevant logs, screenshots, or proof of concept.

Security reports will be reviewed and investigated before any public disclosure.

Please do not include passwords, API keys, service-role keys, database credentials, personal data, or other sensitive information in the report.

## Security Response

The project maintainers will:

1. Review the report.
2. Validate and reproduce the vulnerability when possible.
3. Assess its severity and impact.
4. Apply an appropriate fix.
5. Validate the fix through the project's security and quality checks.
6. Coordinate disclosure when appropriate.

## Scope

This policy applies to the Academia Arcana source code, application infrastructure, CI/CD workflows, and security-sensitive configuration maintained in this repository.
