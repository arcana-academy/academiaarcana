# Core

Infraestrutura transversal da Academia Arcana.

## Regras

- `core` não possui regras específicas de um domínio de negócio.
- Domínios não devem importar detalhes de infraestrutura diretamente para a interface.
- Identidade, contexto e autorização são conceitos distintos.
- A inteligência artificial não possui autoridade implícita sobre dados ou ações.
